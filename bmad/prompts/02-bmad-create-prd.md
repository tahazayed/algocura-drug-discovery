# BMAD PRD handoff

Invoke BMAD `bmad-create-prd` using the approved product brief and `bmad/prd.md` as a draft baseline. Trace each requirement to a feature brief and source-derived technical spec. Specify actor, trigger, preconditions, primary/alternate flows, business rules, API/event/data contracts, validation, authorization, and testable acceptance criteria. Mark unsupported details as OPEN. Run `bmad-validate-prd` and do not mark the PRD approved until owners resolve blockers.
